## 范围

记录原版 Python 启动器、C++ ADG 服务与 ARGoS 3 Foot-bot 控制器的实验流程。构建依赖和前置条件见 [运行与开发关系](../relations/README.md)。

## ARGOS-001 样例实验与结果

| 项目 | 内容 |
| --- | --- |
| 状态 | `partial`。已实测 Python 配置生成与输入缺失处理，并核对 RPC 与统计实现。端到端运行待验收 |
| 前置条件 | Ubuntu 22.04 等配齐原版依赖的环境，已构建 `build/server/ADG_server` 和 Foot-bot 控制器插件，`argos3` 位于 PATH |
| 正常行为 | `run_sim.py` 使用地图和场景生成 `.argos`，随后启动 ADG 服务与 ARGoS。Foot-bot 控制器经 RPC 领取动作并上报进度。服务收到结束请求后追加统计 CSV 并输出 JSON 摘要 |
| 异常与边界 | 地图或场景文件缺失，以及请求的机器人数量超过场景条数时，启动器会报错退出。路径的默认参数需结合具体数据使用，样例命令显式提供路径及坐标顺序 |

### 验收条件

从仓库根目录运行 [README 的 XY 随机场景样例](../../README.md#running-with-visualization)，选用 `--num_agents=50` 和 `--flip_coord=0` 的命令。脚本和样例位置以当前检出的 README 为准。

| 场景 | 操作 | 可观察结果 | 证据 |
| --- | --- | --- | --- |
| 实验配置 | 使用随机样例生成 50 台机器人的可视化和无界面 XML | 两份 XML 均含 50 台 Foot-bot、指定 RPC 端口及 0.1 秒仿真步长，可视化配置含 Qt OpenGL 节点 | Windows / Python 3.11.15 实测配置生成层 |
| 可视化实验 | 运行上述样例 | 生成 `output.argos`，加载控制器，执行完成后写入一行统计并输出 JSON 摘要 | 待端到端实测 |
| 无界面实验 | 在同一命令追加 `--headless=True` | 无窗口运行，两个进程按实验流程结束，产生相同格式的统计 | 待端到端实测 |
| 启动输入缺失 | 使用不存在的地图或场景文件 | 启动器报出缺失路径，经错误分支退出 | Windows / Python 3.11.15 实测地图和场景缺失分支 |
