# Spec 索引

按功能拆分 Spec，并为每条可独立验收的行为分配稳定 ID。从 [Spec 模板](template.md) 创建新规范。

## 条目状态

| 状态 | 含义 |
| --- | --- |
| `implemented` | 在文档写明的适用环境内已实现，约定的验收已有可核查结果。 |
| `partial` | 已实现一部分行为，或必要验收仍有待确认的范围。写明已验证的部分和剩余缺口。 |
| `planned` | 目标行为尚未实现。写明预期验收条件。 |

同一份 Spec 可以有不同状态的条目。接口定义、配置声明和模拟测试提供各自覆盖范围的证据。需要真实环境验收时，记录当前证据和待验环境。
