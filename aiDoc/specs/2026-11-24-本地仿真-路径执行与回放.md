# 2026-11-24（本地仿真）：路径执行与回放

## 范围

记录 [本地 3D 仿真](../../sim/README.md) 的场景导入、动作依赖、物理结果、CLI 和浏览器入口。本次执行证据来自 Windows / Node.js 24.22.3。

## SIM-001 场景导入

**状态** `implemented`。用户可选随机障碍或仓库样例，或提交 Moving AI 地图、场景和路径三份文本。按场景行顺序读取前 N 台机器人，路径编号从 0 开始。XY/YX 选项只转换路径坐标，地图和场景使用 XY。每台机器人可使用统一格式的显式时间戳，时间戳须严格递增。无时间戳时从 0 按步递增。路径允许原地等待和四邻接移动。

| 场景 | 操作 | 可观察结果 | 证据 |
| --- | --- | --- | --- |
| 同一场景的 XY 与 YX 路径 | 使用匹配的坐标顺序导入 50 条路径 | 两组输入解析为相同的机器人路径，选错顺序得到输入错误 | [冒烟测试](../../sim/smoke.test.mjs#L24) |
| 原地等待与时间戳 | 导入含等待的路径，分别使用显式时间戳和默认时间。再提交时间重复或混用格式的路径 | 两种有效输入均保留等待点，默认时间从 0 递增。无效时间格式返回输入错误 | 自定义输入实测 |
| 无效路径或物理参数 | 传入跨格路径、越界摩擦系数或空冲量对象 | 返回可读的输入错误，拒绝该次仿真 | [冒烟测试](../../sim/smoke.test.mjs#L84) |

[输入实现](../../sim/input.mjs) 校验网格尺寸、障碍、起终点、重复起点及数据上限。时间戳用于动作依赖判断。

## SIM-002 动作依赖与仿真完成

**状态** `implemented`。[ADG](../../sim/adg.mjs) 将网格路径转换为转向和半格移动。同一机器人的动作按顺序推进，跨机器人前置动作完成后释放依赖。已完成该机器人的计划动作时计入 `stats.finished`。实际位置记录在回放帧中，可在完成动作后随碰撞或外力改变。

| 场景 | 操作 | 可观察结果 | 证据 |
| --- | --- | --- | --- |
| 跨机器人依赖 | 对随机样例计算索引化 ADG 和逐对基准 | 依赖方向与边数一致 | [冒烟测试](../../sim/smoke.test.mjs#L24) |
| 常规样例 | 随机障碍和仓库各运行 50 台机器人 | 均完成全部动作。末帧位置与目标水平距离小于 0.06 米 | [冒烟测试](../../sim/smoke.test.mjs#L55) |
| 仓库规模样例 | `node sim/server.mjs run --example warehouse --agents 1000` | 本次完成 1,000 台、219,419 个动作。仿真时间为 390.167 秒 | CLI 实测，退出码 0 |

## SIM-003 物理与接触统计

**状态** `implemented`。[物理引擎](../../sim/physics.mjs) 以 1/60 秒为固定步长推进刚体，支持调整速度、加速度、转速、地面摩擦及对指定机器人施加平面冲量。接触计数记录接触开始，持续接触计一次，地板支撑接触排除在统计之外。回放采样间隔由 `stats.sampleSeconds` 给出。

| 场景 | 操作 | 可观察结果 | 证据 |
| --- | --- | --- | --- |
| 墙体、机器人和地面 | 对不同布置施加相同冲量，并改变地面摩擦 | 墙体或机器人接触可观测。摩擦增大时自由滑行距离缩短 | [冒烟测试](../../sim/smoke.test.mjs#L69) |

## SIM-004 CLI 退出状态与回放文件

**状态** `implemented`。[CLI](../../sim/server.mjs#L92) 的 `run` 将统计输出到标准输出，可用 `--output` 将版本化回放写入文件。完成为退出码 0，输入或执行错误为 1，依赖阻塞或达到仿真时限为 2。阻塞或超时仍可导出已生成的回放。

| 场景 | 操作 | 可观察结果 | 证据 |
| --- | --- | --- | --- |
| 正常运行 | `node sim/server.mjs run --example random --agents 2 --output trace.json` | 退出码 0，回放版本为 1，统计显示 2 台完成 | CLI 实测 |
| 仿真时限 | 在同一命令加 `--max-seconds 1` | 退出码 2，`outcome=timeout`，回放含已生成的帧 | CLI 实测 |
| 非法机器人数量 | `node sim/server.mjs run --example random --agents 0` | 退出码 1，标准错误提示数量无效 | CLI 实测 |

## SIM-005 HTTP 仿真入口

**状态** `implemented`，验收覆盖本机 HTTP 页面与基本仿真请求。服务默认监听 `127.0.0.1:8765`。向 `POST /api/simulate` 提交 JSON，工作线程返回仿真回放，输入错误返回 HTTP 400 和可读的 `error` 字段。

| 场景 | 操作 | 可观察结果 | 证据 |
| --- | --- | --- | --- |
| 本地服务 | 启动 `node sim/server.mjs`，请求 `GET /` 和 `GET /healthz` | 首页返回 HTTP 200。健康端点返回 `{"ready":true}`，可用于检查服务是否启动 | 本机 HTTP 实测 |
| 正常仿真 | 提交 `{"example":"random","agents":2}` | HTTP 200，回放版本为 1，统计显示 2 台完成 | 本机 HTTP 实测 |
| 非法机器人数量 | 提交 `{"example":"random","agents":0}` | HTTP 400，返回中文输入错误 | 本机 HTTP 实测 |
| 自定义 YX 路径 | 提交 [3 × 2 网格样例](../relations/README.md#自定义场景请求) | HTTP 200，1 台机器人完成，回放目标归一化为 `[2,1]` | 本机 HTTP 实测 |

复现命令见 [HTTP 验收](../relations/README.md#http-验收)。CLI 和 HTTP 的平台验收范围见 [GAP-002](known-gaps.md)。
