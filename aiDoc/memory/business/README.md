# 业务记录规则

- 已确认的需求变化涉及多次任务、接口兼容或运维交接时，从 [业务记录模板](template.md) 建立记录。
- 需要跟进的记录放入 `active/`。将当前结论、待交付内容和待验收范围写清楚，并关联相应 Spec 或缺口。目录在写入首条记录时创建。
- 达到记录约定的验收条件后，将其移入 `done/`，写明最终结果和验证证据。交付中仍存在的缺口继续在 [已知缺口](../../specs/known-gaps.md) 跟踪。
- 业务行为变更时同步修改相关 Spec。记录中的历史用语保留其时间背景，已被替代的长期决策同步更新 [项目记忆](../README.md)。
