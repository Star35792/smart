# SMART 项目工程文档

SMART 用于在物理仿真中执行和评估已有的多智能体路径规划（MAPF）结果。开发和协作从以下入口开始。

| 入口 | 内容 |
| --- | --- |
| [协作规则](../AGENTS.md) | AI 和开发者的协作、修改与验证约定 |
| [Spec 索引](specs/README.md) | 仿真行为、实现状态和验收条件 |
| [模块索引](modules/README.md) | 本地 3D、ARGoS 和配套模块的职责与入口 |
| [运行与开发关系](relations/README.md) | 数据流、启动、构建、验证与发布 |
| [项目记忆](memory/README.md) | 跨任务适用的项目约定 |
| [已知缺口](specs/known-gaps.md) | 尚缺验收证据的场景和关闭条件 |

用源码、运行配置和可复现的验证结果确认现状，用 Spec 记录已确认的行为契约。发现差异时，先记录复现结果和验证范围，再依据确认后的需求修复实现或更新契约。
